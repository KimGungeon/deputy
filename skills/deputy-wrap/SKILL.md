# 인계 남기기

지금 상태를 다음 세션이 이어받을 수 있게 GitHub 이슈에 기록한다.
로컬 파일이 아니라 이슈에 남기는 이유는, 사람이 폰으로 읽고 다른 세션도 볼 수 있기 때문이다.

내가 착수한 이슈마다 다음을 `deputy note <번호>` 로 남긴다:

1. **지금까지 한 것** — 커밋 해시나 파일 경로로 구체적으로
2. **확인된 사실** — 추측과 명확히 구분한다. 확인 안 된 건 "미확인"이라고 쓴다
3. **다음에 할 일** — 명령어 단위로. "테스트 고치기"가 아니라 `pytest tests/api/test_auth.py -x`
4. **막힌 지점** — 무엇을 시도했고 왜 안 됐는지
5. **건드리면 안 되는 것** — 이어받는 세션이 깨뜨릴 만한 것

파생 이슈를 만들어 둔 게 있으면 부모 이슈에 목록으로 남긴다. 부모는 파생이 다 닫히기
전에는 닫히지 않으므로, 이어받는 세션이 무엇부터 봐야 하는지 분명해진다.

그다음:

- 커밋할 게 있으면 담당 브랜치에 커밋한다. `main` 으로 push 하지 않는다
- `deputy status` 로 남은 작업을 확인하고, 넘길 게 있으면 해당 세션에 메시지를 보낸다

추측을 사실처럼 쓰지 않는다. 인계 문서의 거짓말은 다음 세션의 몇 시간을 태운다.
